# Python HTTP Download Speed Test

Консольный скрипт на Python, который делает **10 последовательных HTTP/HTTPS-запросов** к указанному URL, полностью дочитывает каждый ответ и измеряет среднюю эффективную скорость получения данных.

## Требования

Python 3.10 или новее. Сторонние библиотеки не нужны.

## Запуск

```bash
python3 speed_test.py "https://example.com/large-file.jpg"
```

Замените пример URL на прямую ссылку на доступный файл. Каждый запрос ожидает полного ответа до перехода к следующему. При HTTP-ошибке, проблеме соединения или тайм-ауте скрипт останавливается с ненулевым кодом завершения.

## Дополнительно реализовано

Помимо обязательных требований тестового задания, в скрипт добавлены:

- **Проверка URL до начала измерений:** допускаются только `http://` и `https://`, проверяется наличие имени сервера и корректность указанного порта.
- **Обработка ошибок:** отдельные сообщения для HTTP-ошибок (например, 404), сбоев соединения и тайм-аутов. При неудачном запросе тест прекращается, чтобы не показывать неполную статистику как успешный результат.
- **Ограничение ожидания:** `timeout=30` для блокирующих сетевых операций; это не общий лимит времени скачивания файла.
- **Чтение ответа блоками по 64 КиБ:** файл не сохраняется на диск и не загружается целиком в оперативную память; объём считается по реально прочитанным байтам.
- **Запрос с заголовком `Cache-Control: no-cache`:** снижает риск использования неактуального кешированного ответа, но не гарантирует обход кешей.
- **Корректные коды завершения и поток ошибок:** `0` при успехе, `1` при ошибке; диагностические сообщения направляются в `stderr`. Это удобно при запуске из скриптов и CI/CD.

Для реализации используется только стандартная библиотека Python — устанавливать зависимости не требуется.

## Что выводится

- Время каждого запроса — **секунды (с)**.
- Объём скачанных данных — **мебибайты (МиБ)**; 1 МиБ = 1 048 576 байт.
- Средняя скорость — **МиБ/с**.

Среднее время = сумма длительностей 10 запросов / 10.

Средняя скорость = общее количество полученных байтов / сумма длительностей 10 запросов / 1 048 576.

Измерение включает ожидание ответа и чтение тела ответа. Оно характеризует скорость загрузки **с конкретного URL**, а не максимальную скорость интернет-подключения. Заголовок `Cache-Control: no-cache` просит проверить актуальность ответа, но не гарантирует полного обхода промежуточных кешей. Тайм-аут 30 секунд применяется к блокирующим сетевым операциям, а не как общий лимит всей загрузки.
